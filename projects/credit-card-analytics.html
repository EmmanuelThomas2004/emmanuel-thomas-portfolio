Credit Card and Financial Transaction Analytics

An end-to-end financial data analytics project involving customer credit profiles, credit card portfolios, transaction patterns and merchant performance.

The workflow includes data profiling using Microsoft Excel, data cleaning and preparation using Python and Pandas, SQL-based business analysis and validation using MySQL, and interactive Power BI dashboards developed using data modelling and DAX.

Project Overview

The project turns raw financial datasets into business intelligence through a workflow spanning Microsoft Excel profiling, Python and Pandas data preparation, MySQL analysis and validation, and Power BI modelling and dashboards.

Financial Data → Excel Profiling → Python / Pandas → MySQL → Power BI / DAX → Business Insights

Business Problem

Customer credit profiles, card portfolios, transaction activity and merchant performance need to be examined together to understand financial characteristics and payment behaviour. The analysis is structured to explore customer and credit segments, card distribution, transaction values and volumes, payment preferences, and merchant and geographical patterns.

Dataset Overview

Users

Customer demographic and financial information — 2,000 records.

Cards

Credit and debit card information — 6,146 records.

Transactions

Transaction and merchant information — 100,000 records.

The documented transaction period is January 1–31, 2010. The combined datasets contain 108,146 records. Raw and cleaned dataset downloads are linked from the project repository because the data files are hosted externally.

Tools and Technologies

Microsoft Excel Python Pandas MySQL SQL Power BI DAX

Data Profiling and Cleaning

Microsoft Excel was used to inspect dataset structures and column names, review record counts and data types, identify missing values and inconsistencies, inspect unique values and categorical distributions, and understand relationships between the datasets.

Python and Pandas Implementation

Three Python scripts prepare the Users, Cards and Transactions datasets. The documented checks and preparation steps include data type inspection, financial value conversion, date handling, missing-value checks, duplicate checks and data consistency inspection.

SQL Analysis and Validation

MySQL queries cover customer and card analysis, card brand and type distribution, transaction volume and value, payment methods, merchant and geographical patterns, customer spending behaviour, and credit and financial profiles. Validation includes record counts, duplicates, missing values, primary and foreign keys, customer-card relationships, transaction amounts and data consistency.

Power BI Data Modelling and DAX

The model connects Users to Cards and Transactions by Customer ID, and Cards to Transactions by Card ID. DAX measures and calculated columns support customer, card, credit, income, transaction and payment analysis, including customer activity, credit scores, debt, income groups, transaction amounts and online transaction rate.
